# v0.10.0 Pilot Archive

The final v0.10.0 source state is preserved by the annotated Git tag
`v0.10.0-pilot-archive` at commit
`05bd18f6cce15a4cfae8ee090bd13525c1f20095`.

`v0.10.0-pilot-artifacts.zip` contains the secret-scanned generated artifacts
that were intentionally excluded from Git in the v0 project:

- Custom ReAct and LangChain-compatible pilot traces.
- Summary JSON and CSV tables.
- SVG figures.
- Framework comparison and mitigation reports.
- DeepSeek smoke trace and report.

The archive is retained for historical reproduction only. New experiments must
use the v1 named run structure.
